# Network Forensics

Network forensics and PCAP analysis write-ups using Wireshark, from a SOC / Blue Team point of view.

Each write-up follows how I investigated a packet capture step by step: what I looked for, which Wireshark filters I used, and what I learned along the way.

> Note: answers (flags) are not included, only the investigation process and the concepts, so these can be shared without spoiling the challenges.
